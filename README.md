# 우주 단어 탐험대 (Earth Explorer)

초등학교 5학년을 위한 중학생 수준 지구과학 영어 단어 학습 게임입니다.

- 쉬움·보통은 4지선다, 어려움은 영어 철자 직접 입력
- 오답 노트와 복습 라운드, 일일 퀘스트, 레벨·배지, 7일 학습 기록
- 키보드 단축키 (숫자 1~4로 선택, Enter로 다음 문제)
- 진행 상황은 브라우저 localStorage에 저장 (서버·API 키 불필요)

## 로컬 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint    # 타입 체크
npm run build   # dist/ 생성
```
